# 实施记录

## 2026-09-13

- 安装源：微软 .NET 10 release-metadata；锁定 10.0.401，下载后校验 SHA512。
- 项目目录已由用户明确指定，因此在该目录的功能分支实施，不另建外部工作目录。
- 已完成可运行 WPF 骨架、透明帧播放、Alpha 阈值、拖拽和显示器相对位置规则。
- 已连通 12 个动作、点击连击、3/10 分钟闲置行为、任务完成 Victory 和全屏暂停。
- 已连通每日任务、日程、跨日重置、5 秒单槽撤销、JSON 原子保存与损坏备份恢复。
- 已加入统一右键面板、当前用户开机启动、单实例唤醒、全屏去抖隐藏和有限保存重试。
- 自动测试 161 项；资源检查覆盖 12 动作、94 帧。`scripts/verify.ps1` 为统一验证门。
- 已产出 `artifacts/publish/win-x64` 自包含发布目录，并从含空格路径、不同工作目录启动成功。
- 已加入受限测试数据目录和可复现性能脚本；完整长测结果为冷启动最大 1236.83ms、无交互 CPU 0.3153%、私有内存 149.41MiB、隐藏 CPU 0.0385%。
- 当前动画为满足工程契约的粗加工透明占位帧，不代表正式美术验收通过。
- 已加入真实无边框全屏端到端探针；它严格验证探针成为前台、桌宠隐藏和退出全屏后恢复，并将非交互桌面单独报告为环境受限。
- 已接通 Alpha 掩码到 WS_EX_TRANSPARENT 的实时输入路由；跨进程窗口命中探针验证透明角落下穿、身体区域保留桌宠输入。
- 已统一面板退出、Alt+F4 和普通窗口关闭路径；退出序列等待最终快照保存，重复关闭只执行一次。
- 已接入系统时间变更与睡眠恢复广播；收到消息后立即执行跨日重置和全屏可见性复核，显示器、DPI 与系统设置变化继续触发窗口重排。
- 已接入 Windows 注销/关机会话结束路径；最终快照与普通保存严格串行，最多等待 2 秒，不无限阻止系统结束会话。
- 已完成运行时素材降级与 96 MiB LRU 帧缓存；单动作损坏只回退该动作，整份清单或 Idle 损坏时使用内置透明保底帧，并拒绝越界重解析路径。
- 已完成确定性自动行为调度：参数来自外置清单，Idle 按 70/30 静止/微动节奏采样，20–40 秒抽样短距离 Walk，边界前缩短或换向，面板打开时抑制自动 Walk；真实窗口冒烟验证了横向移动。
- 已完成单调时钟帧采样、下一帧边界预约、DPI 分版本后台解码、Alpha 掩码随帧缓存和旧请求丢弃；隐藏时取消排队解码并停止新请求。
- 已完成独立 EffectWindow：Sleep 气泡、Battle 的 1 朵玫瑰/3 片花瓣/1 个星光、Victory 星光与拖拽气泡均不改变主体 240×300 DIP 比例。真实窗口探针验证特效层扩大到 360×420 px、包含点击穿透与禁止激活样式。
- 已完成统一管理面板领域接线：持久化三 Tab 会话、每日任务与日程命令、撤销/错误反馈、自启动与退出入口均由 `ControlPanelViewModel` 统一绑定；TaskCompleted 只注册一次并路由到交互重置与 Victory。
- 已完成面板生命周期与几何规则：右键切换、打开前跨日检查、一次定位、Esc/失活关闭，以及显示器拓扑变化时仅越界 Clamp；新增 `scripts/test-control-panel.ps1` 作为桌面 UI 回归探针。
- 管理面板的 WPF/VM 自动回归已纳入 161 项测试；本轮因原生 GUI 运行额度限制未执行完整跨进程右键探针，不能替代人工实测。
- 单实例通知现在会在 2 秒退出窗口内短间隔重试，延迟建立的主实例管道也能收到固定 wake 意图；最终通知失败写入不含用户正文的结构化事件。
- 全屏检测已接入系统前台窗口 WinEvent，并保留 500ms 轮询兜底；候选策略明确排除自身、Shell、隐藏与最小化窗口，只覆盖工作区的最大化窗口不算全屏。
- 退出序列在开始时关闭管理面板并冻结新交互意图；最终保存完成后才释放窗口与资源，Flush 意外抛错时也保证执行一次终结并由上层记录失败。
- Dispatcher/AppDomain 未处理异常会先写白名单诊断字段，再在 2 秒内尽力保存最终快照；保存回调异常被隔离并记录，严重异常仍按平台默认路径终止程序。
- 日志轮换收紧为活动文件、`.1`、`.2` 共 3×2MiB；当前与备份 JSON 同时损坏时保留原文件和隔离副本并使用安全默认值。
- 待完成：在已解锁交互桌面运行全屏探针和透明边缘快速点击人工时序验收，以及 Win10/混合 DPI/多显示器硬件矩阵。
- 自包含发布改为经过校验的临时目录构建与安全替换，防止重复发布夹带陈旧文件；发布布局回归已覆盖含空格复制路径、不同当前工作目录和隔离透明帧替换。
