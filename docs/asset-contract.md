# 动画资产契约

当前 `assets/character/generated/` 是 `placeholder` 粗加工资产，仅验证透明 PNG、统一画布、foot anchor、帧数、时序和状态切换。基准角色图由内置 ImageGen 生成，提示词要求日漫 Q 版贵族女剑士、奶油金长发、深蓝蝴蝶结、蓝紫眼、白/深蓝/暗红/金服装、白金高筒靴和西洋细剑，透明背景。

- 逻辑画布：480×600；默认显示：240×300 DIP。
- foot anchor：(240,560)；所有人物帧保持同一画布和脚部基准。
- PNG 必须为带 Alpha 的 32 位格式，人物和细剑均不得裁切。
- 正式资产必须逐动作重新绘制关键姿势；不得把当前几何变换帧当作正式动画。
- 正式资产替换时保留清单路径或同步更新 `config/animations.json`，无需修改程序代码。
