# 故障恢复验收记录

## 自动验证

- 正常 JSON 保存和 Unicode 内容、横向比例往返。
- 当前文件损坏时从最近备份恢复。
- 当前与备份均损坏时保留隔离副本并使用安全默认值。
- 日志仅记录事件码、版本、异常类型和 HResult，不记录异常消息或任务正文。
- 保存队列串行写入；写入期间的新修改合并为一次后续写入。
- 退出 Flush 等待进行中的写入，并追加一次最新快照保存。
- `scripts/test-graceful-shutdown.ps1` 向真实发布进程发送普通窗口关闭请求；进程在 5 秒内以 0 退出，并在退出前写出 `data.json`、`settings.json` 和最终横向比例。
- 系统时间变更以及手动/自动睡眠恢复消息会立即触发跨日检查与全屏可见性复核；消息分类已自动测试，真实电源状态切换仍保留在实机矩阵。
- 单次保存最多尝试三次；持续失败后保持 dirty，后续操作可再次触发恢复保存。

## 客观限制

- 如果运行数据目录持续不可写，三次重试后仍可能无法落盘；程序记录 `save-failed` 诊断事件，但若日志目录也不可写，只能保留内存状态直到进程结束。
- 系统强制结束进程、电源中断或超过系统注销时限时，无法承诺异步保存完成。
- 当前自动测试覆盖协调保存队列；真实磁盘只读、磁盘满和会话注销广播仍需故障注入/实机验证。
