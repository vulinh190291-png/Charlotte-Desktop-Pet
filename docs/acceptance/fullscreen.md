# 全屏显隐验收

## 自动探针

先完成发布，再从已解锁桌面的前台 PowerShell 窗口运行：

```powershell
.\scripts\publish.ps1
.\scripts\test-fullscreen.ps1
```

探针会启动隔离数据目录下的已发布桌宠，创建一个覆盖桌宠当前显示器完整物理边界的无边框置顶窗口，并验证：

1. 桌宠启动时可见。
2. 探针确实成为系统前台窗口。
3. 全屏状态稳定 200 ms 后，桌宠在 3 秒内隐藏。
4. 探针退出全屏后，桌宠在 3 秒内恢复。

运行时屏幕会短暂变黑，这是测试窗口本身；探针结束后会关闭桌宠测试进程。成功时进程退出码为 0，并输出包含显示器边界及隐藏、恢复耗时的 JSON。

## 退出码

- `0`：无边框全屏进入、退出均通过。
- `1`：探针已成为前台，但桌宠显隐行为不符合预期，或桌宠初始不可见。
- `2`：命令参数错误。
- `3`：执行桌面没有可用前台窗口，无法完成真实前台全屏验收。

Codex 当前的后台命令会话中，`GetForegroundWindow` 返回 0（Idle），因此 2026-09-13 的自动执行被判定为退出码 3，而不是产品失败。矩阵在获得前台交互运行证据前继续保持“未测”。独占全屏（例如游戏独占模式）仍需人工场景单独验证。
