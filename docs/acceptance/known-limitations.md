# 已知限制

- 当前动画资产为工程占位帧，仅保证画布、透明通道、动作帧数、时序、脚锚点和调度契约；不代表正式 Q 版日漫美术完成。
- 透明窗口的跨进程快速点击、混合 DPI 抓取稳定性和显示器热插拔需要对应桌面环境实测。
- 本版本信任本机日期时间；用户手动跨日期可能再次触发每日任务重置。
- 磁盘持续不可写时，程序会有限重试并记录不含任务正文的诊断事件，但无法承诺最终状态落盘。
- 开机启动是当前用户 HKCU Run 项；不会请求管理员权限。
- AI 对话不属于当前 MVP，因此应用不建立 WebSocket 或 HTTP 对话连接。若后续加入对话模块，默认传输协议按已确认要求使用 HTTP。
